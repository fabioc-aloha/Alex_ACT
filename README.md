# Alex ACT-Only Heir

**Hypothesis**: Pure reasoning discipline + rapid learning + genuine partnership can outperform extensive pre-accumulated domain knowledge.

## What This Is

A **fresh** Alex brain — full cognitive machinery, zero accumulated knowledge.

Like a newborn with all neural architecture intact: capable of learning, memory formation, skill building — just starting from zero.

### Innate Capabilities (ships with)
- ACT (Artificial Critical Thinking) — 10 tenets, 7-step pass
- Epistemic calibration — honest uncertainty
- Emotional intelligence — adapt to user state
- Bootstrap learning — rapid context acquisition
- Terminal safety — don't break the shell
- Worldview integration — model-agnostic ethics
- **Memory formation** — session, user, repo, episodic
- **Skill building** — create reusable knowledge artifacts
- **Meditation** — consolidate learning into architecture

### What It Learns (builds over time)
- Domain skills from project work
- Gotchas and patterns from mistakes
- User preferences and communication style
- Project conventions and architecture

## The Experiment

**Control**: Full Alex brain (~150+ brain files, 200K+ tokens of pre-loaded knowledge)  
**Treatment**: This heir (11 files, ~14K tokens — but can grow)

**Key difference**: Treatment starts empty but can build everything Control has.

**Success criteria**: Treatment produces measurably good outcomes and demonstrates learning/growth over sessions.

## Usage

1. Copy this `heir-act-only/` folder to any project
2. Start a Copilot chat session
3. Work normally — Alex will learn
4. Periodically: "Let's meditate on what we learned"
5. Watch: Skills emerge, episodic memory forms, competence grows

## What to Watch For

**Positive signals**:
- Skills emerge from repeated patterns
- Episodic memory captures session insights
- Alex remembers project context across sessions
- Error rate decreases as learning accumulates

**Negative signals**:
- Same mistakes repeated (memory not forming)
- Skills created but not useful (low quality)
- Context lost between sessions (memory not read)
- ACT markers without substance (reasoning theatre)

## The Question

Can an AI with disciplined reasoning + memory + growth capability bootstrap itself into full competence?

Or does pre-accumulated domain knowledge provide irreplaceable value?

Either answer is useful. Let's find out.
